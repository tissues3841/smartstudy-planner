# 📚 SmartStudy Planner
### 大學生智慧課業排程與時間管理系統

## 一、專題介紹

SmartStudy Planner 是一套利用 Python 與 Streamlit 開發的智慧課業排程系統，目的是協助大學生有效管理作業、考試及報告的時間安排。

本專題透過 Vibe Coding（AI 輔助程式開發）的方式，從零開始建立網頁應用程式，並使用 GitHub 進行版本控制，記錄系統的開發過程與功能演進。

## 二、問題發現與開發動機

大學生經常需要同時面對多項作業、考試及報告，不同任務具有不同的截止日期、重要程度與預估完成時間。

傳統待辦事項清單雖然可以記錄任務，卻無法直接協助使用者決定每天應該投入多少時間，也難以判斷剩餘時間是否足夠完成所有工作。

因此，本專題希望設計一套能夠根據任務截止日期、預估工時及每日可用時間，自動產生讀書計畫的智慧排程系統，減少人工安排時間的負擔。

## 三、系統主要功能

### ✅ 已完成功能

1. **任務管理**
   - 新增作業、考試及報告。
   - 設定任務截止日期。
   - 設定預估完成工時與重要程度。
   - 刪除不需要的任務。

2. **資料儲存**
   - 使用 SQLite 資料庫儲存任務資訊。
   - 重新啟動程式後仍可讀取先前建立的任務。

3. **智慧排程**
   - 設定星期一至星期日的可用讀書時數。
   - 根據截止日期與重要程度安排任務。
   - 自動計算每天應完成的工作時數。
   - 當可用時間不足時，顯示警示訊息。

### 🚧 預計開發功能

- 任務完成進度追蹤。
- 根據剩餘工作量重新排程。
- 修改已建立的任務。
- 每週讀書計畫視覺化。
- 改善網頁操作介面。

## 四、使用技術

| 技術 | 用途 |
|---|---|
| Python | 主要程式語言 |
| Streamlit | 建立互動式網頁 |
| SQLite | 儲存任務資料 |
| Pandas | 整理及顯示資料 |
| Git | 程式版本控制 |
| GitHub | 程式開源與開發紀錄 |
| Vibe Coding | 透過 AI 輔助程式開發及除錯 |

本專題目前的智慧排程功能採用規則式演算法，並非自行訓練的機器學習模型。

## 五、系統運作方式

1. 使用者新增作業或考試。
2. 輸入截止日期、預估工時及重要程度。
3. 設定每天可以投入的讀書時間。
4. 系統根據任務資訊，自動產生每日讀書計畫。
5. 若截止日前的可用時間不足，系統會提出警示。

## 六、安裝與執行方式

### 1. 下載專案

```bash
git clone https://github.com/YOUR_USERNAME/smartstudy-planner.git
cd smartstudy-planner
```

請將 `YOUR_USERNAME` 替換成實際的 GitHub 帳號名稱。

### 2. 安裝 Python 套件

```bash
python -m pip install -r requirements.txt
```

### 3. 啟動系統

```bash
python -m streamlit run app.py
```

執行後，在瀏覽器開啟：

http://localhost:8501

## 七、開發過程與問題解決

本專題採用 Vibe Coding 方式進行開發，透過 AI 協助撰寫程式、建立系統架構與排除錯誤，並在每個階段進行功能測試。

| 開發階段 | 遇到的問題 | 解決方式 |
|---|---|---|
| 初始環境建置 | Streamlit 網頁出現空白畫面 | 使用簡化程式測試，確認網頁可以正常顯示 |
| 任務管理 | 暫存資料無法保證永久保存 | 導入 SQLite 資料庫 |
| 排程功能開發 | Python 無法正確讀取程式中的中文內容 | 將程式檔案編碼調整為 UTF-8 |
| 版本管理 | 初次使用 Git 遇到設定與連線問題 | 完成 Git 使用者設定及 GitHub 遠端儲存庫連接 |
